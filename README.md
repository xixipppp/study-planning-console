# 成考学习管家（专升本）

一个单文件、可离线运行的成人高考（专升本）刷题与备考助手。打开即用，无需服务器、无需登录。

## ✨ 功能概览

- **三科刷题**：政治 / 英语 / 高数二，按模块专项练习、随机、顺序、自适应（错题为先 + SM-2 间隔复习）多种模式。
- **错题本 & 重刷**：答错的题自动进入错题本，支持单题重刷与批量重刷。
- **考点速记 & 记忆口诀**：按科目查阅核心考点，关键考点自动匹配记忆口诀。
- **速记资料库**：文本资料全文搜索。
- **公式卡**：高数二公式 + 例题，可朗读。
- **阅读原文**：英语阅读理解配套原文（内置 3 篇）。
- **AI 讲题**：内置公共 Key，打开即用的 AI 讲解（可填自己的 Key 覆盖）。
- **学习管家**：每日/每周计划、专注计时、模考预测、学习报告。
- **本地自包含**：所有参考数据随 `seed-data.js` 打包，离线 / GitHub Pages / 本地双击均可完整运行；答题、错题、收藏、笔记存于本机浏览器（localStorage），与云端互不冲突。

## 🚀 使用方法

### 方式一：GitHub Pages 在线打开（推荐）
直接访问上面的链接即可。仓库已开启 Pages（`main` 分支、`/` 根目录），打开就是一个完整可用的刷题应用；所有题库与参考数据都内置在 `seed-data.js` 中，即使断网也能正常刷。

### 方式二：本地下载后打开（完全离线）
把本仓库克隆或下载到本地，确保 `index.html` 与 `seed-data.js` 在同一目录，双击 `index.html` 即可（建议 Chrome / Edge）。

### 方式三：用 WorkBuddy 云端空间运行（数据可回流）
在 WorkBuddy 云端打开 `index.html`，进入「我的 → 数据管理 → 导出种子数据」，即可把云端题库导出为 `seed-data.js` 覆盖本地版本，获得你自己的完整题库。

## 📝 关于内置题库

`seed-data.js` 内置一份**真实的专升本（政治 / 英语 / 高数二）起始题库**（约 127 题，含考点、口诀、资料、公式卡与英语阅读原文），用于保证「打开即能刷题」。

如果你在 WorkBuddy 云端拥有更完整的私有题库，可在云端空间运行本应用并点「导出种子数据」，用导出的 `seed-data.js` 覆盖本文件即可无缝替换，无需改动 `index.html`。

## ⚠️ 说明

- 内置 AI 讲题使用内置公共 Key，额度有限；可在「刷题页 → AI 助手」中填入你自己的硅基流动 Key 以获得稳定服务。
- 错题、收藏、笔记等用户数据保存在本机浏览器，换设备/清缓存会丢失，重要内容建议定期在云端同步。
